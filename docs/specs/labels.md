# Labels handling

The backup app has a concept of labels - these are predefined simple text string tha allow documents to be flagged for specific reasons.  For example there is a label 'House' that allows tagging of documents as being related to the house.

The following defines areas where i would like to see improvements.

## Manage labels (Future)

A separate tab that allows creating, modification or deleting of labels.

Requires a change to the backend to support.

## Search

You can search by labels - currently the control just accepts strings but it would be better to select the labels from the known label values.

## Document View add Labels

Currently you can add labels to a document or remove them again - its a bit clunky - pops up a rather plain dialog.  Can this be improved? I don't see there as ever being an enourmous number of labels proably about 20 to 30 if that makes a difference.
